All resources used by the Direct3D pipeline derive from two basic resource types: 
	buffers and textures.
	
A buffer is a collection of raw data (elements); a texture is a collection of texels (texture elements).

Buffer Types
	Vertex Buffer
	Index Buffer
	Constant Buffer( shader-constant buffer ) : A constant buffer allows you to efficiently supply shader constants data to the pipeline
